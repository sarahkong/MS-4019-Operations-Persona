# MS-4019-Operations-Persona

## Applied Exercise – Operations Leadership Workflows with Microsoft 365 Copilot Agents

## Learning Objectives

In this exercise, you will use Microsoft 365 Copilot prebuilt agents and a custom agent to support operations leadership workflows such as operational planning, resource management, process improvement, issue resolution, and business reporting.
By completing these activities, you will learn how to:
1. Use the Researcher agent to gather and analyse operational information across the organisation.
2. Use the Analyst agent to identify trends, risks, bottlenecks, and performance insights from operational data.
3. Generate operations-ready summaries, status reports, and leadership briefings.
4. Create a custom Operations Insights Agent in Microsoft 365 Copilot.
5. Apply retrieval-based AI experiences to operations management scenarios.
6. Use Copilot agents to support decision-making, workforce planning, process optimisation, and business continuity activities.

## Prerequisites
Before starting this exercise, ensure you have access to:
- Microsoft 365 Copilot
- Researcher agent
- Analyst agent
- Create Agent in Microsoft 365 Copilot

## Demo 1 – Analyse Performance and Identify Bottlenecks with Analyst
Use the Analyst agent to identify operational bottlenecks, delays, performance trends, and areas for improvement.

### Steps
​1. Open Microsoft 365 Copilot Chat.
2. Expand the Agents menu.
3. Select Analyst.
4. Enter the prompt.

### Prompt
Analyse operational data and identify performance bottlenecks impacting service delivery.

Highlight:

- Areas with recurring delays or inefficiencies
- Trends affecting productivity or throughput
- Teams or processes experiencing the highest workload
- Potential risks to meeting operational targets
- Recommendations to improve operational performance

### Expected Outcome 
Analyst generates insights that help operations leaders understand:

- Performance trends across operational activities
- Recurring bottlenecks affecting productivity
- Process inefficiencies and operational risks
- Workload distribution and resource challenges
- Opportunities to improve service delivery and operational effectiveness

The analysis provides a data-driven view of operational performance, enabling leaders to prioritise improvements, address bottlenecks, and make informed decisions.
  
## Demo 2 – Analyse Operational Context with Researcher
Use the Researcher agent to identify operational trends, risks, and priorities impacting day-to-day business operations.

### Steps
1. Open Microsoft 365 Copilot Chat.
2. Expand the Agents menu.
3. Select Researcher.
4. Enter the following prompt.

### Prompt
Summarize the key operational trends impacting our organization this quarter. Identify recurring operational challenges, resource constraints, process improvement opportunities, and areas that may require leadership attention.

### Expected Outcome
Researcher generates a summary of:

- Key operational trends affecting the business
- Recurring issues, risks, or bottlenecks identified across available business data
- Resource, staffing, or workload considerations
- Process improvement opportunities
- Operational priorities requiring management or leadership attention
- Insights that can support operational planning and decision-making

This output provides operations leaders with a consolidated view of current operational health and areas requiring action.

## Demo 2 – Create an Operations Insights Agent with Agent Builder
Use Agent Builder to create a custom agent that helps operations leaders monitor performance, identify risks, and generate operational updates.

### Steps
1. Open Microsoft 365 Copilot Chat.
2. Select Create an Agent
3. Choose Create from Description.
4. Enter the following description.

You are an Operations Insights Agent that helps operations managers analyse operational performance, identify bottlenecks, track risks, and generate leadership-ready updates.

When responding:

- Summarise operational status and key performance trends
- Highlight risks, delays, and recurring issues
- Identify workload and resource concerns
- Recommend actions to improve operational efficiency
- Generate concise summaries for leadership reviews and team meetings

5. Select create
6. Add relevant knowledge sources such as operational reports, process documentation, service metrics, and team resources.
7. Save the agent as Operations Insights Agent.

### Test the Agent
Enter the prompt:

Review this week's operational information and create an executive summary highlighting performance trends, bottlenecks, operational risks, and recommended actions.

### Expected Outcome

The Operations Insights Agent:

- Reviews operational information from connected data sources
- Identifies bottlenecks, delays, and performance concerns
- Summarises operational health and business impact
- Provides actionable recommendations
- Generates leadership-ready updates that can be shared with managers and stakeholders

This demonstrates how Agent Builder can transform frequently repeated operational reporting and analysis tasks into a reusable AI assistant that supports daily operations management.
